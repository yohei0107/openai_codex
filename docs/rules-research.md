# ルール調査の記録（2026年10月21日）

Web上の解説記事・アプリの説明・Q&Aを開いて本文を確認し、FAIRWAY の仕様を決めた記録です。ニギリは地域や仲間内で流派が分かれるため、「多くの資料で一致する点」を既定にし、分かれる点は開始前に選べるようにしました。ゾロ目の倍率（+1／×2）のように、資料に裏付けがなくても利用者のグループで使っているルールは、選択肢として残しています。

## ラスベガス

| 項目 | 資料の主流 | FAIRWAY の扱い |
| --- | --- | --- |
| 2桁の作り方 | 小さい方を十の位（4と6なら46）[SQORE][enGolf] | 同じ |
| 一の位 | 差をそのまま数えるのが基本。一の位を切り捨てる・十の位だけで数える流派もある[enGolf][SQORE] | 利用者の基本ルールで「繰り上げ（11点差→20点）」。あり・なしを選択（既定あり） |
| 10打以上 | 9打カットが主流[SQORE]。10打以上の人を前にする（4と10なら104）方式もある[golf.com] | 「そのまま（その人を前に）」（既定）と「9打として計算」を選択 |
| ペアの決め方 | 打順で1番・4番 対 2番・3番が定番。固定・組み直し・ローテーションもある[SQORE] | 打順3通り・18ホール固定3通り・毎ホール組み直す・3または6ホールごとの交代から選択 |
| バーディ | 相手の数字を反転（46→64）[enGolf][SQORE]。反転の代わりに2倍、併用もある[SQORE] | 反転のあり・なしと、2倍のあり・なしを別々に選択 |
| イーグル | 反転＋倍率（2〜4倍）[The Fried Egg][enGolf] | 倍率をバーディと同じ・×2〜×4から選択（既定×2） |
| ペア2人ともバーディ | 2倍・4倍などの例がある | 倍率をバーディと同じ・×2〜×4から選択。当てはまる倍率のうち最大を使う |
| 両ペアにバーディ | 相殺（反転しない）が多数[enGolf]。選べるアプリもある[SQORE] | 「相殺」（既定。倍率も打ち消す）か「両方反転」を選択 |
| ダブルパー | 自ペアの数字を反転する流派がある[SQORE][日新] | あり・なしを選択（既定なし） |
| 反転される2人が同スコア | 「数字が変わらないだけ」と明記した資料あり[enGolf] | 特別扱いなし・倍率+1・倍率×2から選択（既定×2。利用者のルール） |
| リーチ（プッシュ） | 2倍。宣言のタイミングと回数を事前に決める[enGolf][SQORE] | 宣言した人ごとに2倍。1人あたりの上限（ハーフごと／ラウンド通して）と、宣言できるタイミング（表示のみ）を選択 |
| 同点 | 次のホールを2倍、続けば3倍[Golf Info Central ほか]。倍々の例もある | 持ち越しなし・+1ずつ・倍々から選択（既定+1ずつ） |

## オリンピック

- 全員がグリーンに乗ったら、カップから遠い順に金4・銀3・銅2・鉄1。1パットで沈めたら得点[SQORE][enGolf]
- グリーンの外から直接入ったらダイヤモンド5点[SQORE][日新]
- 点を取った人が他の全員から受け取る。差し引き＝自分の点×人数−全員の合計[SQORE][日新]
- FAIRWAY では、利用者の指定で「パット数から計算する」のをやめ、各自が獲得した点を直接入力する形にした。金・銀・銅・鉄・ダイヤのボタンと、独自ルール（くず鉄−1など）用の数字入力がある

## スコアマッチ

- 「スコアマッチ」という名前の資料は見つからず、中身は「ヨコ」（ホールごとの1対1の勝ち負け）にあたる[日新][ゴルナレ]
- ヨコは1ホールの負けが1点。3〜4人なら全員と1対1の総当たり[SQORE]
- FAIRWAY は総当たりで、勝ち＋1・負け−1・引き分け0。結果画面に相手ごとの勝ち越し表を出す。ハンデは未対応
