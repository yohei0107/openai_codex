# ラスベガスの判定仕様

ルールの根拠と、流派が分かれる点の扱いは [ルール調査の記録](rules-research.md) を参照してください。

## 開始前に決めること

ラウンドを始める前に、設定画面で全員でルールを決めます。「このルールで開始」を押すまでスコアは入力できず、開始後は変更できません。

### 基本ルール

| 項目 | 選択肢（★は最初の選択） |
| --- | --- |
| ペアの決め方 | ★打順 1番・4番 対 2番・3番／打順 1番・2番 対 3番・4番／打順 1番・3番 対 2番・4番／18ホール固定（3通り）／毎ホール組み直す／3ホールごと・6ホールごとに交代 |
| 一の位の繰り上げ | ★あり（11点差 → 20点）／なし |

### 追加ルール

| 項目 | 選択肢（★は最初の選択） |
| --- | --- |
| バーディで相手の数字を反転（46 → 64） | ★あり／なし |
| バーディで点差を2倍 | あり／★なし |
| イーグル以上のとき | バーディと同じ／★×2／×3／×4 |
| ペア2人ともバーディ以上のとき | ★バーディと同じ／×2／×3／×4 |
| 両ペアともバーディ以上のとき | ★相殺（反転も倍率もなし）／両方とも反転 |
| 反転される2人が同スコア（ゾロ目） | 特別扱いなし／★倍率を2倍／倍率に1加算 |
| ダブルパー（パーの2倍以上）で自分たちの数字を反転 | あり／★なし |
| 10打以上の数え方 | ★そのまま（その人を前に：4と10 → 104）／9打として計算 |
| 同点のとき | 持ち越しなし／★次のホールを2倍（続けば3倍、4倍…）／次のホールを2倍（続けば4倍、8倍…） |
| リーチの上限（1人あたり） | ★上限なし／1回／2回／3回（★ハーフごと／ラウンド通して） |
| リーチを宣言できるのは | ★ティーショットの前／2打目の前／グリーンに乗る前／いつでも（画面に表示するだけで、アプリでは判定しません） |

「毎ホール組み直す」を選んだ場合は、ラスベガスの画面でホールごとに「プレイヤー1と組む人」を選びます。選んでいないホールは、プレイヤー1・4のペアになります。

旧保存データで項目が欠けている場合は、従来の動き（反転なし、繰り上げなし、両方反転、倍率なし、持ち越しなし、リーチ上限なし、打順で組む）で補います。リーチを回数で記録した旧データ（`pushes`）は、その回数で計算します。

## 計算順序

1. ペアを決めます。打順で組む場合は前ホールのスコア順で打順を決めます（1番ホールはプレイヤー順、同点は直前の順番を維持）。
2. 2人の打数を並べて2桁にします。少ない打数を十の位、多い打数を一の位に置きます（4と6なら46）。10打以上は、設定により9打として数えるか、その人の打数を前に置きます（4と10なら104）。
3. 各ペアで、パーを下回った人を見ます。1打下ならバーディ、2打以上下ならイーグル以上、2人ともならペア2人のバーディです。
4. 両ペアにバーディ以上がいる場合、「相殺」なら反転も倍率もかけません。
5. 相手ペアにバーディ以上がいて、反転ありの設定なら、自ペアの数字を反転します（大きい方を前に：46 → 64）。ダブルパーの人がいて、その設定がありなら、自ペアの数字を反転します。どちらの理由でも、反転は1回です。
6. 反転される2人が同じスコアなら、ゾロ目を1件と数えます（数字は変わりません）。
7. 倍率を掛け合わせます。
   - リーチ：`2 ** 宣言した人数`
   - ゾロ目：「2倍」なら `× 2 ** 件数`、「1加算」ならリーチの倍率に件数を足す
   - バーディ・イーグル：「バーディで2倍」「イーグル以上」「ペア2人ともバーディ」で選んだ倍率のうち、当てはまる中で一番大きいもの（両ペアとも反転の場合は、両ペアのうち大きい方）
   - 同点の持ち越し：直前に続いた同点の回数 `t` に応じて、「+1ずつ」なら `1 + t`、「倍々」なら `2 ** t`。未入力のホールで連続は途切れます
8. 差（数字の大きい方 − 小さい方）を出します。一の位の繰り上げがありなら、10点単位に切り上げます（11 → 20、29 → 30。ちょうど10の倍数はそのまま）。
9. 差 × 最終倍率を、数字が小さいペアの各メンバーに加点し、相手ペアの各メンバーから同じ点を引きます。両ペアの数字が同じなら同点（0点）です。

## 計算例

| 状況 | 計算 | 結果 |
| --- | --- | --- |
| 46 対 57、繰り上げあり | 差11 → 20 | 46のペアが20点 |
| 相手が4打・6打、自分たちが3打（バーディ）・5打 | 46 → 64 に反転。64 − 35 = 29 | 繰り上げなしなら29点、ありなら30点 |
| 上と同じで「バーディで点差を2倍」あり、繰り上げなし | 29 × 2 | 58点 |
| パー4で8打の人がいるペア（6打との組）、ダブルパーの反転あり | 68 → 86 | 相手が45なら41点の負け（繰り上げありなら50点） |

## 制限と対象外

- 全員のスコア（1〜20打）を入力したホールだけを計算します。
- リーチは1人1ホール1回です。宣言のタイミングは表示するだけで、判定はしません。
- 金額・精算は扱いません。
