# FAIRWAY

4人のラウンドでスコアとオリンピックの点を記録し、ラスベガス、オリンピック、スコアマッチ（ヨコ）を管理する日本語のWebアプリ。スマートフォン・デスクトップ対応。金額・賭け金・精算・決済の機能はありません。

試用版の公開先：https://fairway-games.pages.dev （Cloudflare Pages）

## 開発

Node.js 22.12以降を使用します。

```sh
npm ci
npm run dev
```

```sh
npm test          # 計算ロジックのテスト
npm run test:e2e  # ブラウザでの入力・保存復元・集計のテスト
npm run build    # dist/ に静的配信用ファイルを出力
```

ブラウザテストは、Linux では `@sparticuz/chromium` 同梱のバイナリを、それ以外（macOS など）ではインストール済みの Google Chrome を使います。テスト用の開発サーバーはポート5174で起動します。

公開は `dist/` を Cloudflare Pages のプロジェクト `fairway-games` へアップロードします。

```sh
npm run build
npx wrangler pages deploy dist --project-name fairway-games --branch main
```

## 実装済みの機能

- 4人の名前、コース名、9/18ホール、ホールごとのパー設定
- スコアとオリンピックの点の直接入力、増減、入力消去、入力範囲の検証（パット数の入力はなし）
- 入力欄の各選手の名前の下に、ラスベガスの累計を表示
- 前ホールのスコア順による次ホールのオナー判定。同点時は直前の順番を維持
- ラスベガス：開始前に基本ルール（ペアの決め方・一の位の繰り上げ）と追加ルール（バーディの反転・2倍、イーグルとペア2人バーディの倍率、両ペアバーディの相殺、ゾロ目、ダブルパーの反転、10打以上の数え方、同点の持ち越し、リーチの上限とタイミング）を決めて固定
- オリンピック：獲得した点を直接入力（金4・銀3・銅2・鉄1・ダイヤ5のボタン付き）、差し引きの表示
- スコアマッチ（ホールマッチ・ヨコ）：各相手とのアップダウン（UP／DN／AS）を、そのホールまでの累計で表示
- スコアカード（各ホールのラスベガス・オリンピックの点つき）、ゲーム別順位、端末内自動保存、JSON書き出し

保存先は同じブラウザのlocalStorageです。共同編集・端末間同期・クラウド保存・オフライン起動・JSON再取込は未実装です。ブラウザのデータ消去で記録が失われるため、必要な記録はJSONで書き出してください。

## ルール

ラウンド開始前の設定画面で、流派によって違うルールを選びます。開始後は固定です。変更する場合は、記録を必要に応じてJSONへ書き出し、新しいラウンドを開始してください。

- ラスベガスの計算手順：[ラスベガスの仕様](docs/vegas-rules.md)
- 各ルールの根拠と、流派が分かれる点の扱い：[ルール調査の記録](docs/rules-research.md)

### ラスベガスの計算例

| 状況 | 計算 | 結果 |
| --- | --- | --- |
| 46 対 57、一の位の繰り上げあり | 差11 → 20 | 46のペアが20点 |
| 相手が4打・6打、自分たちが3打（バーディ）・5打 | 46 → 64 に反転。64 − 35 = 29 | 繰り上げなしなら29点、ありなら30点 |

計算の順番と全項目は [ラスベガスの仕様](docs/vegas-rules.md) にあります。

### オリンピック

全員がグリーンに乗ったら、カップから遠い順に金・銀・銅・鉄。1パットで沈めた人は、そのメダルの点を入力します。グリーンの外から直接入ったらダイヤ5点。差し引きは「自分の点×4人−全員の点の合計」で、全員分を足すと0になります。

### スコアマッチ（ヨコ）

各ホールで全員と1対1でスコアを比べ、相手ごとに勝ち越し（UP）・負け越し（DN）・並び（AS）を累計で表示します。2人とも入力したホールから数えます。ハンデは未対応です。
