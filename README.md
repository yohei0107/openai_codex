# FAIRWAY

4人のラウンドでスコア・パット数を記録し、ラスベガス、オリンピック、スコアマッチを管理する日本語のWebアプリ。スマートフォン・デスクトップ対応。金額・賭け金・精算・決済の機能はありません。

## 開発

Node.js 22.12以降（検証環境：24.19.0）を使用します。

```sh
npm ci --cache /workspace/.npm-cache
npm run dev
```

```sh
npm test          # 計算ロジックのテスト
npm run test:e2e  # Chromiumによる入力・保存復元・集計のテスト
npm run build    # dist/ に静的配信用ファイルを出力
```

ブラウザテストはLinux向け `@sparticuz/chromium` 同梱バイナリを利用します。Playwrightの追加ブラウザダウンロードは不要です。開発サーバーの標準ポートは5173です。本番配信には `dist/` を静的ホスティングしてください。公開・配信は未実施です。

## 実装済みの機能

- 4人の名前、コース名、9/18ホール、ホールごとのパー設定
- スコア・パット数の直接入力、増減、入力消去、入力範囲・矛盾の検証
- 前ホールのスコア順による次ホールのオナー判定。同点時は直前の順番を維持
- ラスベガスの3通りのチーム分けと差分ポイント集計
- オリンピックのメダル指定と1パットによる得点
- スコアマッチの対戦相手ごとの勝利数集計
- スコアカード、ゲーム別順位、端末内自動保存、JSON書き出し

保存先は同じブラウザのlocalStorageです。共同編集・端末間同期・クラウド保存・オフライン起動・JSON再取込は未実装です。ブラウザのデータ消去で記録が失われるため、必要な記録はJSONで書き出してください。

## ラスベガスの追加ルール

ラウンド開始前の設定画面で以下を選び、「このルールで開始」を押します。開始後はルールを固定します。変更する場合は、記録を必要に応じてJSONへ書き出し、新しいラウンドを開始してください。

- バーディーによる相手チームの十の位・一の位の反転を有効／無効にできます。
- バーディーを受けた相手チームの2人が同じスコア（ゾロ目）のときの方式を、**倍率を2倍** または **倍率に1加算** から選べます。
- ホールごとにリーチ／プッシュを複数回追加・取消できます。1回で2倍、2回で4倍、3回で8倍。別のホールには繰り越しません。
- 反転前後の数字、適用理由、差分、最終倍率、獲得ポイントを表示します。
- 保存済みの旧ラウンドは従来のポイントを保持します。新しい方式を使う場合は新しいラウンドを開始してください。

### 計算例

パー4で、Aのスコアが3・4、Bが5・5、プッシュ1回の場合：

| 開始前の設定 | 計算 | Aの各メンバー | Bの各メンバー |
| --- | --- | --- | --- |
| 倍率を2倍 | (55 − 34) × (2 × 2) | +84 pt | −84 pt |
| 倍率に1加算 | (55 − 34) × (2 + 1) | +63 pt | −63 pt |

ゾロ目の判定は相手チーム内の同スコアであり、両チームの数字が等しい引き分けとは区別します。

追加仕様・適用順序・テスト範囲・調査記録は [ラスベガスの仕様](docs/vegas-rules.md) を参照してください。

## 公開資料の調査状況

**ユーザー指定のルールを実装した段階で、公開記事による裏付けの確認は未完了です。** 調査済みと偽って出典を付けていません。

再調査では、許可済みサイトへの接続は成功しましたが、Google検索がJavaScript実行を要求し、実行後の検索リクエストはHTTP 429でした。ALBAのサイト内検索は実行できましたが、得られたラスベガスの結果は主に都市・大会の記事で、このゲームの該当ルールは確認できませんでした。ゴルフパートナーのサイト内検索も該当記事なし／全ブログ検索タイムアウトでした。

代替検索先の `www.bing.com` と `html.duckduckgo.com` は、現在の環境ではHTTP 403で拒否されています。既存の許可先を保持して、この2ドメインを環境設定案に追加済みです。環境設定で保存・公開した後、接続を再確認して外部資料との照合を続ける必要があります。

オリンピックとスコアマッチも、引き続き初期の暫定仕様です。オリンピックは距離順に金4・銀3・銅2・鉄1を手動指定し、1パットで得点。スコアマッチはホールごとに全員と1対1で比較し、勝った相手1人につき1ポイント、同点0です。特殊得点・罰点・ハンディキャップは未実装です。
